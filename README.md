# Site web d'Ogma

Site statique (HTML et CSS, sans outil de compilation), publié avec GitHub Pages.

- `index.html` : accueil
- `confidentialite.html` et `conditions.html` : copies des textes légaux de l'app (`src/features/legal/texts.ts` dans le dépôt Ogma). À mettre à jour en même temps que l'app.
- `support.html` : aide, contact et mentions légales
- `404.html` : page affichée pour une adresse qui n'existe pas
- `assets/` : style, polices (Figtree et Source Serif 4, licence OFL incluse) et images
- `CNAME` : créé par GitHub quand le nom de domaine est branché. Ne pas le supprimer.

Le site n'utilise ni cookies, ni mesure d'audience, ni ressource externe.

À faire quand l'app sera publiée : remplacer « Bientôt sur l'App Store » (dans `index.html`) par le badge officiel d'Apple et le lien vers la fiche de l'app.
